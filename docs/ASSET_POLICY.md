# 素材与授权 / Asset rights

本仓库保存历史工程。原 MIT 文件不代表作者能够替全部第三方素材授予商用、修改
或原文件再分发许可；原片尾署名也不自动等于获得授权。

| 内容 | 当前处理 |
|---|---|
| 自有剧情、代码、文档 | 保留原有适用许可；新商业工程单独管理 |
| RPG Maker 官方素材与运行库 | 按产品、购买资格和具体素材条款核查 |
| 第三方脚本 | 核查脚本头和补充授权；带非商用说明的条目不直接复制到新作 |
| 音乐、图像、音效、字体 | 逐项记录来源、作者、商用及再分发证据 |
| 实况视频 | 链接原作者页面，不下载重传 |
| 新 SVG 标识 | 原创文档图形，随文档采用本仓库 MIT 许可 |

改名、改色、去水印或 AI 重绘不能代替授权。RPG Maker 条款已有更新，应查阅
[当前规则](https://www.rpgmakerofficial.com/support/rule/)，不能根据旧印象推断跨引擎权限。

原作 714 个文件已登记审计，但**完整登记不代表授权全部通过**。未核清旧素材没有
被带入新工程。本次文档改版不删除历史资源、不重写 Git 历史；后续清理先明确路径、
保存备份并说明对现有版本的影响。

Rights holders may contact the owner through GitHub with the specific file and supporting
ownership/license information. Third-party content keeps its own terms. New development
uses original replacements or documented licensed material.
